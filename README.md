SQL and PL/SQL Assignment
How to Run the SQL Queries
Follow these steps to run the SQL queries and PL/SQL programs in this assignment:
First thing to do is to Open Oracle SQL Developer.
Second things to do is to Connect to the Oracle database using the required username and password.
Third thing is to  Open the SQL files included in this repository.
Fourth is to Make sure the required tables and data you  have been created before running the queries.
Fifth is to Run the SQL queries in the order provided in the assignment.
Sixth is, queries that use GROUP BY, joins, or subqueries, execute each query and check the displayed results.
Seventh is, For ALTER, UPDATE, and DELETE statements, execute the statements carefully and verify the changes.
Eightieth is, For PL/SQL programs, enable DBMS Output in SQL Developer.
Ninth is ,For PL/SQL programs, enable DBMS Output in SQL Developer..
Tenth is to Check the output in the DBMS Output window.

 Requirement are:
 Oracle DBMs.
 Oracle SQLDeveloper
 SQL/PLSQL files included in this  repository.
 Required tables and simple data.
